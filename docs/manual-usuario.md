# Manual de usuario SIGAF

## Acceso

1. Ir a `/login`
2. Usar credenciales asignadas o cuentas demo del README
3. El menú lateral y el dashboard cambian según tu rol

## Navegación común

- **Dashboard:** KPIs, gráficos y accesos rápidos
- **Documentos / Expedientes:** listados, filtros y detalle
- **Archivo físico:** ubicaciones, cajas y carpetas
- **Préstamos:** solicitar, aprobar, devolver
- **Búsqueda / QR:** localizar por texto o código
- **Reportes:** exportar información
- **Notificaciones:** alertas del sistema

## Consejos

- Los jefes de dependencia solo ven información de su área
- Los usuarios de consulta no pueden modificar registros
- Cierra sesión desde el menú de tu avatar
